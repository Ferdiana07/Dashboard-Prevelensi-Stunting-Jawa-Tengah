# Asal data lampiran

Kedua berkas adalah salinan lokal lampiran pengguna dan tidak diunduh dari pihak ketiga selama implementasi:

- `stunting.csv`: `C:/Users/LOQ/Downloads/prevalensi_stunting_jateng_2019_2022_clean.csv`.
- `jateng.geojson`: `C:/Users/LOQ/Downloads/batas_kabkota_jateng.geojson`.

CSV memuat 105 baris pada 2019, 2021, dan 2022. GeoJSON memuat 35 batas kabupaten/kota dan mempertahankan koordinat asli. Aplikasi menggabungkan keduanya berdasarkan `kode_wilayah`.

Lampiran tidak menyertakan metadata sumber upstream, versi batas administratif, metode survei, atau lisensi penggunaan kembali. Asal tersebut belum diverifikasi; tidak ada klaim atribusi ke BIG, BPS, Kemenkes, GitHub, maupun Zenodo. Untuk publikasi akademik, lengkapi sitasi dan izin sesuai sumber data asli yang digunakan penyusun dataset.
