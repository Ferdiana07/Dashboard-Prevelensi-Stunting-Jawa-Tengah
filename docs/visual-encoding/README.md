# Stimulus visual tersamar

Dua belas tangkapan browser dari dashboard, disiapkan untuk peneliti. Gambar berasal dari render aplikasi dengan judul/kontrol/penjelasan disamarkan; data, sumbu, legenda, dan marks tetap terlihat. Berkas bukan hasil generasi gambar atau rekonstruksi geometri.

Kunci kondisi, sumber commit, aturan masking, serta panduan penyajian ada di [VISUAL_ENCODING.md](../../VISUAL_ENCODING.md). Jangan membagikan kunci kondisi kepada responden sebelum menjawab. Acak ID/urutan stimulus pada penyajian sebenarnya.
